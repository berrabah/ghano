# Translate Extension

This example Chrome extension translates the currently selected text when the
button in the popup is clicked. It opens a new tab with Google Translate showing
the translated result.

## Installation
1. Open Chrome and navigate to `chrome://extensions`.
2. Enable "Developer mode" in the top right.
3. Click "Load unpacked" and select this `translate-extension` folder.
4. Highlight some text on any page and click the extension's icon, then hit the
   "Translate Selected Text" button to open Google Translate in a new tab.
